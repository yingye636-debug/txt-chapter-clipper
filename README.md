# TXT 章节裁剪助手（TXT Chapter Clipper）

一个轻量、纯本地运行的 **TXT 文本章节裁剪工具**，手机与电脑浏览器打开即用，无需安装任何软件，也不会上传你的文件。

适合从长篇 TXT 小说、电子书或文档中，快速挑选单章、多章或指定区间章节，合并导出为一个新的 `.txt` 文件。

## 在线使用
直接点击仓库顶部 About 区域的在线链接即可打开使用（支持在手机浏览器中「添加到主屏幕」作为轻量 App 使用）。

## 核心功能
- **纯本地运行**：所有文件解析与导出均在浏览器本地完成，不上传服务器，断网离线亦可正常使用。
- **自动识别中文编码**：内置 UTF-8、GBK/GB18030、Big5、UTF-16 自动检测与手动切换，告别中文乱码。
- **智能目录识别**：默认支持「第X章/回/节」、序章、番外、`Chapter X` 等常见标题格式，也支持自定义正则表达式或按固定字数分段。
- **灵活选择章节**：支持按标题搜索、单选/多选、输入起止序号一键「区间快选」、全选、反选与「仅看已选」。
- **章节正文预览**：导出前可点开任意章节预览正文，并支持在预览窗口直接切换上下章和勾选。
- **自定义导出**：可自定义导出文件名、章节分隔样式、是否附加目录清单以及 UTF-8 BOM 头，支持下载 `.txt` 或一键复制文本。

## 使用方法
1. 打开在线页面（或下载本仓库的 `index.html` 在电脑/手机本地浏览器打开）。
2. 点击「选择本地 TXT 文件」导入文档（电脑端可直接拖拽文件进页面）。
3. 勾选需要的章节，或输入起止序号点击「选中区间」。
4. 点击底部「裁剪导出」，确认文件名后即可下载裁剪好的 `.txt` 文件。
